## 7. データ追加手順

1. `items.ts` / `monsters.ts` にエントリを追加する（`id` は一意）。
2. 出現させる場合は `spawnTables.ts` に重みと階層を追加する。
3. 新しい効果種別が必要なら `ItemEffect` の union と `EffectResolver` に分岐を追加する。
4. レシピは `recipes.ts` に `inputs`（順不同）と `output`, `turns` を追加する。
5. `npm test` で `tests/replay.test.ts` が落ちた場合、乱数消費順が変わった可能性がある。意図した変更なら fixture を再生成する。
